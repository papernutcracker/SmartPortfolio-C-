Ознайомитися з принципами побудови об'єктно-орієнтованих систем на мові C#, застосуванням колекцій, LINQ-запитів, розділенням логіки на шари (Models, Services, Managers) та проведенням комплексного рефакторингу консольного інтерфейсу користувача.

## 💻 Технічне завдання та етапи виконання

### Етап 1: Англомовна локалізація та уніфікація інтерфейсу (Рефакторинг `Program.cs`)

Поточна версія коду містить змішування мов (UA/EN) та ручне перемикання кодування консолі, що часто призводить до багів відображення символів.

1. **Повне чищення кодування:** Видалити рядки встановлення кодування `UTF-8` (`Console.OutputEncoding` / `Console.InputEncoding`).


2. **Перехід на English Only:** Перевести всі виводи в консоль, змінні, назви секторів, пункти меню та текстові повідомлення виключно на **англійську мову**. Змінну `bool isUa` та всі конструкції `switch` / `if-else`, що відповідали за вибір мови, необхідно повністю видалити з логіки додатка.



### Етап 2: Реалізація бізнес-логіки та CRUD операцій

Забезпечити стабільну роботу з активами у класі `PortfolioManager`:

* **Додавання акції (`AddStock`):** Написати перевірку на дублікати. Якщо акція з таким тікером уже існує в портфелі, замість додавання нового об'єкта оновлювати кількість акцій (`Shares`) та перераховувати нову середню ціну (`AveragePrice`).
* **Видалення акції (`RemoveStock`):** Реалізувати безпечне видалення елемента з колекції за його унікальним тікером.

### Етап 3: Інтеграція LINQ для аналітики портфеля

У меню "View Assets" або окремому аналітичному модулі реалізувати обчислення за допомогою **LINQ**:

1. **Розподіл за секторами:** Сформувати звіт, який групує акції за сектором (`Sector`) та показує відсоткову частку кожного сектора від загальної вартості всього портфеля.
2. **Фільтрація за P/E Ratio:** Додати метод для пошуку потенційно недооцінених компаній (наприклад, фільтрація акцій, у яких `PERatio < 15` та `PERatio > 0`).

### Етап 4: Розробка сервісу "AI Advisor" (Емуляція)

Створити `AIAdvisorService`, який аналізує поточний профіль користувача (`UserProfile`):

* Якщо рівень користувача `Beginner` — сервіс має виводити базові поради щодо диверсифікації та безпеки портфеля.
* Якщо рівень `Experienced` — сервіс шукає недооцінені активи (використовуючи фільтр P/E з Етапу 3) та пропонує варіанти для ребалансування.

## 📝 Критерії оцінювання (Checklist)

* [ ] Код повністю компілюється під target framework `.NET 10.0`.


* [ ] Усі текстові виводи, назви опцій меню, сектори та повідомлення про помилки переведені на англійську мову.
* [ ] Повністю прибрано логіку перемикання мов (`isUa`) та примусове кодування UTF-8.
* [ ] Реалізовано логіку об'єднання акцій при повторному додаванні однакового тікера.
* [ ] Розрахунок аналітики (частка секторів, середній дохід) реалізовано через LINQ-запити (`GroupBy`, `Sum`, `Select`).
* [ ] Програма демонструє коректну обробку некоректного введення користувача (перевірка на double/int для ціни та кількості).
